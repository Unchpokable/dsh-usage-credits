# DSH Usage & Credits

Плагин для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): показывает **баланс API Credits** и **расход текущей сессии** прямо под композером — в юанях, долларах и вашей локальной валюте по живому курсу.

## Что видно

| Где | Что |
|---|---|
| Док под композером | `¥12.34 ($1.85, 151 ₽)` — пополненный баланс: юань первым, затем доллары и локальная валюта |
| Док под композером | `−¥0.65` — расход сессии, с иконкой чека; при наведении полная расшифровка |
| Подсказка | Источник курса, `¥1 = … ₽`, `$1 = … ¥`, время обновления, состояние кэша, кто из провайдеров ответил |
| Settings → API Credits | Баланс в исходных кошельках (`¥12.34 + $1.85`), эквивалент в локальной валюте, выбор локальной валюты, режим отображения расхода, детали курса, кнопка обновления |

Пилюля баланса повторяет оформление штатных `N tok`: тот же ряд, тот же ритм, только токены темы.

## Почему расход — не «токены × цена»

DeepSeek считает входные токены двумя разными бакетами:

* **cache hit** — префикс уже в кэше, примерно **в 50 раз дешевле** промаха;
* **cache miss** — новый ввод по полной цене.

Длинная агентская сессия легко набирает десятки миллионов входных токенов, потому что контекст отправляется заново на каждом шаге. UI считает их все, но почти все — попадания в кэш. Умножение общего числа на цену промаха завышает счёт в десятки раз.

Плагин считает каждый бакет отдельно, прямо из проекции `tokenUsage`:

```
cost = (uncachedInput + cacheWrite) × miss
     + cacheRead                     × hit
     + output                        × output
     × (peak ? 2 : 1)
```

Реальные цифры для сессии на 13.9M токенов с 99% попаданий: **¥0.65**, тогда как «всё по цене промаха» дало бы ¥27.80 — ошибка в 42 раза.

## Тарифы

Официальные цены DeepSeek за 1M токенов. Первое значение — off-peak, peak-часы стоят ровно вдвое дороже:

| Модель | Валюта | Cache hit | Cache miss | Output |
|---|---|---|---|---|
| `deepseek-flash` | CNY | 0.02 / 0.04 | 1 / 2 | 4 / 8 |
| `deepseek-flash` | USD | 0.003 / 0.006 | 0.15 / 0.30 | 0.60 / 1.20 |
| `deepseek-v4-pro` | CNY | 0.15 / 0.30 | 4.5 / 9 | 13.5 / 27 |
| `deepseek-v4-pro` | USD | 0.022 / 0.044 | 0.66 / 1.32 | 1.98 / 3.96 |

Оба прайса хранятся нативно, поэтому долларовый кошелёк не пересчитывается через юань. Семейство модели определяется по маршрутам, записанным в сессии.

**Peak** — 01:00–04:00 и 06:00–10:00 UTC по будням (09:00–12:00 и 14:00–18:00 по Пекину), всё остальное, включая выходные, — off-peak. Праздники КНР не моделируются: в эти дни цена считается как peak, то есть с запасом. Полоса берётся на момент отрисовки, поэтому сессия через границу peak/off-peak оценивается одной полосой.

## Настройки

* **Локальная валюта** — 60 ходовых валют (RUB по умолчанию, KZT, BYN, EUR, GEL, AMD, TRY, AED, INR, JPY, KRW, …). Названия берутся из `Intl.DisplayNames`, символы — из `Intl.NumberFormat`, ничего не захардкожено по валютам.
* **Расход сессии в** — `Локальная` (пересчёт из юаневого прайса по кросс-курсу, в подсказке показан эквивалент в юанях) или `Пополнение` (валюта самого крупного кошелька, CNY или USD, по своему официальному прайсу).

Обе настройки хранятся в `localStorage`, в пределах браузера.

## Курсы

Основная валюта — юань. Каждый источник отдаёт полную таблицу «сколько единиц валюты за 1 ¥», поэтому локальной можно сделать любую валюту из списка. Все источники опрашиваются одновременно, побеждает **первый валидный** ответ, остальные запросы отменяются.

| id | Endpoint |
|---|---|
| `cbr` | `cbr-xml-daily.ru/daily_json.js` — ЦБ РФ, кросс-курсы из его таблицы |
| `jsdelivr` | `cdn.jsdelivr.net/npm/@fawazahmed0/currency-api` |
| `erapi` | `open.er-api.com/v6/latest/CNY` |
| `fxratesapi` | `api.fxratesapi.com/latest?base=CNY` |
| `exchangerate` | `api.exchangerate-api.com/v4/latest/CNY` |
| `floatrates` | `floatrates.com/daily/cny.json` |

Ответ принимается, только если `0.05 < $/¥ < 0.4`, в таблице не меньше трёх валют и, когда рубль присутствует, `3 < ₽/¥ < 40`. Победивший курс кэшируется на 6 часов, обновляется раз в 30 минут и при возврате фокуса на окно; если сети нет, показывается последний известный курс с пометкой «из кэша». Захардкоженных курсов нет.

## Откуда баланс

Два транспорта по порядку:

1. `ctx.remote.account.getBalance()` — тот же аутентифицированный канал, которым пользуется страница Settings → Account. Важная деталь: динамический клиент-плагин не может достучаться до него через `ctx.remote.account` (песочница проксирует сервис, а не дерево namespace'ов); рабочий путь — `ctx.get('remote.account')`, плюс плагин терпит поздний монтаж namespace.
2. Loopback-роут `/api-credits/balance` на Host-половине, защищённый одноразовым токеном процесса, который Host сам вставляет в отдаваемую страницу. Без токена — `403`.

В любом случае баланс не покидает вашу машину: браузер общается с локальным Host DSH, а тот — с платформой DeepSeek под вашими учётными данными.

## Установка

Корень репозитория **и есть** бандл, поэтому клон сразу пригоден к установке.

```bash
git clone https://github.com/Unchpokable/dsh-usage-credits.git
```

Дальше установите этот каталог как бандл (Plugin Manager → установка бандла из локального пути) либо повторите то, что делает установщик, вручную в профиле:

```bash
cd ~/.dsh/profiles/<profile>
pnpm add /path/to/dsh-usage-credits
```

и добавьте `@local/dsh-api-credits` в `dsh.profile.bundles` в `package.json` профиля. Перезапустите приложение и обновите страницу.

Для баланса нужен вход в аккаунт DeepSeek; без него плагин покажет подсказку о входе, но курс продолжит отображаться.

## Структура

```
package.json        манифест бандла: dsh.bundle.patch + dsh.client
cordis.patch.yml    вставляет строку `api-credits`
index.js            Host-половина: защищённый токеном роут баланса, инъекция в index
client.js           Клиент: стор курсов, две пилюли в доке, страница Settings
locale/{en,ru,zh}.json
icon.svg
```

## Ограничения

* Цены — снимок официального прайса; DeepSeek может их менять. Они собраны в одной таблице `PRICES` в `client.js`.
* Оценка полосы peak не учитывает праздники КНР и считает, что вся сессия шла в текущей полосе.
* Настройки хранятся в браузере, а не в профиле.
* Баланс и расход — оценки для собственного учёта; авторитетная цифра — та, что списывает платформа.
